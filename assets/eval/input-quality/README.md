# 日常输入组合集

92 条手工标注种子（72 个词、20 个句子），生成 1,444 个不重复用例：全拼、尾音简拼、全首字母、交错简拼，以及首部／中部／尾部的漏键、多键、邻键替换、相邻交换；另外包含用户实际按键串和英文／中英混输对照。

运行 `python tools/eval/input_quality.py --binary target/release/qingjian-cli --output target/input-quality-eval`。默认禁用云服务与模型，不读取或写入用户词频。评测输出保存逐条候选、字错误率、首选／前三／前五命中率、解析失败和静态词库中是否存在完整词形。

词形存在不代表读音或排序正确，词形缺失也不代表整句组合无法输入。补入产品词库的常用词仍留在此集合中，故它是回归集，不能作为对微软拼音或陌生语料的泛化证明。冻结中文期刊题材集合仍单独运行；其标准句不加入补丁词库。权重是手工排序参数，不是测量频率。
