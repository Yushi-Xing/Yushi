## 自动测试应覆盖的用例

### 会话、帧和生命周期

- 未 OpenSession 的 Key / Poll / Commit / Privacy / Selection / Surrounding / Position / Hide / Mode / Close 全部拒绝，不能改 Engine。
- 两条连接使用相同外部编号时得到不同内部编号；回包编号仍与各自 DLL 相符。
- 尝试读取、提交、关闭或改变另一连接的隐私与模式；已有会话内容不被越权获取。
- 重开自己的会话、关闭后再开、重复关闭、EOF、坏帧、部分正文与写失败；断线清理自己的会话，不清别人的组句。
- SessionId 为 0 和 u64::MAX；达到会话数量上限后可关闭并恢复容量；大量重复打开不能增加无限会话。
- 兼容保留的单向“输入法已切走”通知有明确受限范围，不能把它当通用的免认证消息入口。
- 帧空／边界／超限、截断前缀／正文、未知枚举和无效 JSON；失败不会半应用状态。

### 全拼、纠错与中英输入

- 全拼、合法简拼、混合简拼、隔音符、ü/v、残缺音节、长句、无候选、分段上屏。
- `mingtain`、`woxiagnqu` 等换位；漏键、多键、邻键、合法音节误拼；首／中／末尾错位；多解歧义。
- 正常拼音、姓名、专业词、英文单词、品牌大小写、`gpt6`、`mp3`、路径、URL 等负例不能被盲目纠正。
- 光标中间插字、Backspace/Delete、Home/End、选词后余串、Esc、Enter 原样输出、标点上屏。
- 上屏学习、原样拒绝、退格重打与撤销、自动造词、个人习惯与模型冲突、坏学习文件。
- 空格、数字、翻页、候选不足时的数字；Shift/Caps/Ctrl/Alt/Win/AltGr 与键盘布局。
- 模型未加载、加载失败、推理失败、模型迟到、候选已被导航后不得换位。

### 诊断、安全和隐私

- 普通／空／缺失／损坏配置；正文、注释、inline table、多行文本、未知字段里的密钥与 URL 凭据。
- 源配置不被修改；导出摘要只含允许字段；解析失败不复制原文件、不把异常原文导出。
- 路径含中文、空格、单引号、美元、反引号；临时目录并发和清理；不执行路径里的脚本片段。
- 正常输入、故障输入与私密输入不出现在 TSF 运行日志；既有旧日志可能含输入，导出不能声称已自动去除历史文本。
- 未知隐私、普通 → 私密、私密 → 普通、同线程换文档、两应用往返；断线重开重新确认。
- 翻译前、等待中、返回时进入私密；已排队和在途请求均取消；不通过真实 API 验证隐私。
- 跨账户／远程／伪服务端／AppContainer／低完整性客户端，分别做 Windows 原生正反例。

### 网络、句译与异步

- 正确 Content-Length、声明超限但无正文、长度恰好上限、chunked 边界和超限、无长度 EOF、空正文。
- HTTP 404/429/500、断流、超时、坏签名、坏 JSON、目标不支持、返回空句／过长句。
- 连续键入、高亮快速切换、翻页、上屏、换焦点、句子文本相同但会话不同、切模型与服务商。
- 缓存命中、缓存容量与字节上限、重复请求、关闭开关、无密钥、取消后的迟到响应。
- 所有网络测试用本机模拟服务或内存替身；不使用真实密钥、不上传真实输入、不对外部 API 制造负载。

## Windows 手工／宿主测试步骤

每个宿主、控件、系统版本执行以下序列，记录预期与实际文本：

1. `nihao` 空格、`jintiantianqihenhao`、简拼与错拼；选首项、次项、翻页后选项。
2. 在拼音中间移动、插入、删除；Esc、Enter；标点、小数与中英混输。
3. 空输入框／有文字／有选区；多行；两控件与两应用往返；主动终止 composition。
4. Shift/Caps 与 Ctrl+C/V/Z、Tab/Shift+Tab、方向键、Home/End；确认宿主快捷键仍可用。
5. 后台服务退出／重启／模拟超时：确认宿主可继续操作、字符没有无提示丢失或重复。
6. 密码控件与 private 标记控件；句译关闭、开启、失败、迟到，普通选词仍输出中文。
7. 100% / 125% / 150% / 200% 缩放、换屏、负坐标、窗口边缘、深浅色。

Win10 与 Win11 真实结果分开记录，32 位与 64 位宿主分开记录。可以在 WSL 跑内核与协议测试，但不能据此勾选上面的 Windows 控件测试。
