# 第一批基础修复文章探针对照

本机调试 CLI，相同冻结输入与答案，共 100 条（正常 64、双漏键 32、用户例 4）。无网络、无学习，真实本地模型单独对照。源码基线 `1ef14cb37dad2ffa4e5c1264468c7d831292e7cc`；after 为 beta.13 修复代码，二进制哈希在 summary 中。

`comparison.json` 记录数据/模型/语料指纹、前后各项准确率、首选变化与回退；`cases.json` 是固定输入，results 保存完整候选，failures 保留失败。调试时间不是发布性能指标；Windows 全集与停键探针以 Release 附件为准，人工应用验收仍待完成。
