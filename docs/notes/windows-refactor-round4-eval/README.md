# 常用词库补充与日常文章评测

基于 beta.6 的固定引擎代码，只追加 19,662 个默认生效的补充词条。基础产品词库仍为 data-v3 的 92,825 个读音条目，原人工补丁 16 条保留；补充库按词形与基础 TSV 及人工补丁去重。新增词库为 503,467 字节，采用结巴与 THUOCL 的 MIT 词表、Unicode 17.0.0 的读音，来源与筛选见 `assets/lexicon/supplement/`。不导入雾凇，不运行第三方下载代码，不调用云服务。

先冻结四篇公开日常文章的 64 个词句、16 个留出种子及 1,123 个组合，再补库，原答案和变体始终不改。`daily-before-*` 和 `daily-after-*` 保存完整分组汇总；前后模型状态分别一致。`comparison.json` 按文本、实际键串、上文逐条核对结果。没有把整句答案塞进词库。

文章整句首选仍为 17/32。双错误、纯简拼、合法音节误写以及“词库收纳了多少词”的错误首选没有因补库而解决；“此剧”挤掉“词库”和“次”挤掉“词”属于路径与上下文问题，需要独立优化。词条存在、能找到候选与首选正确分开统计。

新增词库的能力抽测为 237 条：192 个稳定散列抽样词、28 个新增人工核验词、14 个旧输入对照和 3 个品牌错拼／简拼。新增完整词条覆盖 220/220；自动抽样首选 112/192、前三 181/192；人工核验词首选 24/28、前三 28/28。取件码、付款码、快递柜、抽纸仍有同音首选排序问题。它们是导入能力抽测，不能当作独立文章准确率。

“ 双汇火腿肠 ”的全拼 `shuanghuihuotuichang`、尾字简拼 `shuanghuihuotuic`、漏键 `shuanghuihuotuchang`、末尾互换 `shuanghuihuotuichnag` 均首选正确。康师傅方便面和充电宝全拼也首选正确，不需要模型。

本机原评测全组合和两种模型状态的文章集均保留完整失败；发布附件另有 Windows CI 实际结果。Win11 搜索栏候选被遮挡已经由 beta.6 用户截图证实仍存在，本次补库不声称解决遮挡。整句排序、本地模型体验与真实应用兼容继续保留为待办。

发布门禁在 beta.7 的原生 Windows 检出上发现 LF → CRLF 导致 SHA256 不一致，已阻止安装包发布。beta.8 通过 `.gitattributes` 固定词源与评测数据 LF，生成器也显式 LF；新增开启 `core.autocrlf=true` 的真实 Git 检出回归。原词库内容、筛选与哈希均保持，不把换行差异当作允许跳过哈希验证的理由。
