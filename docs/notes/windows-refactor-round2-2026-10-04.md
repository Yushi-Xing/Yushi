## 评测方法和结果

来源与生成方法见 [期刊诊断集](../../assets/eval/journal/README.md)。4 篇期刊的研究主题由我们改写为 24 条句子，另加 6 条日常对照；不是全文摘录，不是公开权威中文识别基准。人工给定逐字拼音，未向词库添加标准句、未训练或调参迎合样本。小样本及其相关变体不能代表所有中文输入。

每轮 336 个固定输入：30 原拼音、30 带上文、240 单处错拼、30 双处错拼、6 模糊音。相同文本、不同拼音和上文保留为不同样本。冷启动、不学习、不读取个人词库、不调用云服务。产品词库 92,825 条，data-v3 归档 SHA256 见 data.lock，模型使用随包含章·通变，与 Windows 模型加载的优先级一致。

| 配置 / 输入 | 修复前首选 | 修复后首选 | 修复后 CER |
|---|---:|---:|---:|
| 词库+二元模型 / 正常拼音 | 12/30 = 40% | 12/30 = 40% | 13.21% |
| 词库+二元模型 / 错拼 | 32/270 = 11.85% | 32/270 = 11.85% | 35.32% |
| 随包 P2C 模型 / 正常拼音 | 15/30 = 50% | 15/30 = 50% | 11.40% |
| 随包 P2C 模型 / 错拼 | 34/270 = 12.59% | 34/270 = 12.59% | 34.11% |
| 显式模糊音（两种模型配置一致） | 3/6 = 50% | 5/6 = 83.33% | 15.38% |

正常样本未触发整串纠正标记（0/30），但这不能证明没有音节级误纠；完整首选不匹配仍算识别失败。`censi` 的期望“程式”在第 8 位，首选“撑死”，按失败计入。错拼的成功不能全部归因于纠错算法：部分本来即可按前缀或其他切分匹配，报告指标是恢复标准句的成功率。当前整串纠错上限为 24 字母，很多专业长句超出范围，仅音节级纠错参与，这也是后续重点。

修正原评测工具的三类偏差：按文本去重会丢不同错拼；解析失败被排除会虚增百分比；按标准长度挑候选会借用答案。现在以全部样本计分，实际首选按 Unicode 编辑距离计 CER，失败、漏字、增字均计错。自由生成路径也修正字符分母。

原始对照汇总与每条结果在 [评测记录目录](windows-refactor-round2-eval)，包含实际二进制、产品数据、模型和种子指纹。修复前二进制在修复 Core 前构建并保存；四个正式结果的正常/模糊音均使用同一个对应二进制。

## 回归与发布

保留所有既有测试并完整运行，对原翻页用例增加所有键配置、页边界、多次翻页后选词；对连接测试增加每个字节的截断和 1/2/3/7/64 字节分片读取/写入；对原热加载用例增加基础读音在替换、删除、错误配置后的保留断言。新增模糊音逐键、退格重输、原样上屏、规则开关与分隔符，评测去重/错误分母/Unicode 编辑距离，生成器变异复杂度和统计独立检查。第一轮的诊断包路径、保密、文件大小以及 HTTP 边界测试也继续全量执行。

未逐一重写所有历史测试；按关键失效路径增加复杂条件、加强既有断言，并对全套测试运行回归。测试清单与实际执行汇总另附。宿主验收顺序保持：Windows 基础输入框 → 浏览器 → VS Code → 微信；两种系统需分别安装测试。

Windows 三件套版本统一为 0.1.6-beta.2。独立 `windows-preview.yml` 在本 fork 发布预览，门禁包含标签与版本一致、main 祖先检查、Linux/Windows 全 workspace 测试（排除 macOS 壳）、Clippy、Windows PowerShell 原生诊断 ZIP、数据 SHA256、MSVC x64 产物及 x86 DLL、安装器与附件 SHA256。只发布 prerelease，不伪造上游官网签名，也不更改原发布频道。安装包、构建信息与评测 ZIP 一同发布。

本机最终回归：677 条通过、0 失败、2 条默认忽略；另运行原生 PowerShell 诊断 ZIP 1 条通过，Python 生成器/统计 2 条通过。Linux 工作区 Clippy 与 Windows GNU 三组件所有 target 的 Clippy 均通过。MSVC 真编译、Windows 管道测试与 TSF 单元测试待 Actions 执行。

首次 Windows Actions 检出了真实平台差异：未登记请求被服务器关闭后，客户端读取返回 Windows 错误 233（ERROR_PIPE_NOT_CONNECTED），原测试只接受 EOF。断连与拒绝逻辑已生效；修正原生测试为接受 EOF 或明确的 Windows 管道已断开错误 109/233，其他错误和任何返回帧仍然失败。首次 beta.1 标签未发布安装包，保留失败记录；修正后发布 beta.2，不移动旧标签。原生窗口输入的人工验收仍未完成。
