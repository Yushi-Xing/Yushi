Windows 10 / 11 安装测试版，版本 0.1.6-beta.1。

下载 `qingjian-0.1.6-beta.1-windows-x86_64-setup.exe` 安装；同时包含 64 位和 32 位 TSF DLL，供不同位数的应用使用。安装后重启已打开的输入应用，必要时注销再登录。

本次修复显式模糊音被纠错覆盖、`en` 缺少“嗯”、连接会话冲突/断连清理、故障包隐私及评测统计问题。扩展翻页、逐字编辑、传输分片和截断、词库热加载测试，加入 4 篇中文期刊主题改写的固定诊断集。

随包模型下，本机固定诊断集：正常输入首选 15/30（50%），错拼还原 34/270（12.59%），显式模糊音 5/6（83.33%，修复前 3/6）。专业句子的整句输入和长句自动纠错仍不足；不会把有纠正标记当作纠错成功。附件同时保留 Windows CI 的实际结果，具体以该次构建的 `summary.json` 为准。

- `SHA256SUMS`：安装包与附件的 SHA256。
- `build-info.json`：源提交、编译器、数据锁定信息、构建编号、CI 评测汇总。
- `journal-evaluation.zip`：人工读音、每个输入、候选、失败明细、本机前后对照与 Windows CI 结果。

请按以下顺序验收：Windows 基础输入框（记事本、设置搜索）→ 浏览器（普通输入、多行、验证码、密码框）→ VS Code → 微信。每项检查中文/英文切换、数字、标点、长句、翻页、退格、光标编辑和窗口切换；反馈系统版本、应用版本、原始拼音、期望文字与实际结果。
