Windows 10 / 11 安装测试版，版本 0.1.6-beta.11。

下载 `qingjian-0.1.6-beta.11-windows-x86_64-setup.exe`。安装后注销再登录，使系统搜索进程也加载新版；保留 64 位与 32 位 TSF DLL。

新增 Windows 搜索候选显示回退：系统接管候选时由系统显示；允许青简显示时，由搜索进程内的 TSF DLL 在搜索面板内绘制紧凑竖排候选，同时隐藏 Server 的独立置顶窗。支持数字、方向键和鼠标选词、主题与 DPI；相同帧不反复重绘，失焦、取消或结束组句清理窗口。未引入提权、证书安装、进程注入或未公开窗口层级 API。

本机 Windows 26200 已复现独立置顶／owned 弹窗被搜索盖住的问题；新增回退仍需安装后在实际搜索栏验收，不能以普通模拟窗口与 CI 通过声称所有 Win11 搜索版本已修好。若仍被遮挡，运行日志中的显示协商和回退失败错误码不含输入内容。

**全部双拼保留**，本轮不改变输入方案、词库、纠错和模型排序；安装包体积精简另行处理。

默认补入 **19,662 个词形**，覆盖日常组合、食品、生活用品和计算机用语。补充文本约 **492 KiB**，不依赖开启领域词库、本地模型或云服务。来源为 MIT 许可的结巴和 THUOCL，读音采用已核验整词读音、Unicode 17.0.0 单音字及 28 个新增人工核验词；未知多音字与未核验专名暂不导入。来源、原始权重与筛选哈希全部保留，安装包附版权许可声明。

关闭本地模型，“双汇火腿肠”的全拼、尾字简拼、漏一个字母、末尾相邻字母互换均为首选；康师傅方便面、充电宝也能直接输入。保留 beta.6 的纠错、候选排序和停键缓存修复。

本机冻结文章集 1,123 条与原 1,444 条组合前后对照：文章词条覆盖 30/32 → 32/32，正常首选仍为无模型 43/64、有模型 42/64；原正常首选 84/92、单处错拼首选 757/1104 保持，原成功用例无退步。新增词库能力抽测 220/220 可找到完整词条，人工核验词首选 24/28；“取件码、付款码、快递柜、抽纸”仍有同音首选问题。补入词条不等于解决整句排序，也不证明达到微软拼音准确率。Windows CI 实际结果见附件。

**待验收：Win11 搜索栏的新回退显示路径。** 开始菜单及设置应用的其他遮挡不属于本轮统一修复范围。“词库收纳了多少词”、合法音节写错及多处错拼的整句还原仍需继续优化。本包未代码签名、uiAccess 关闭。
