Windows 10 / 11 安装测试版，版本 0.1.6-beta.10。

下载 `qingjian-0.1.6-beta.10-windows-x86_64-setup.exe`。安装后重启输入应用，必要时注销再登录；保留 64 位与 32 位 TSF DLL。

默认补入 **19,662 个词形**，覆盖日常组合、食品、生活用品和计算机用语。补充文本约 **492 KiB**，不依赖开启领域词库、本地模型或云服务。来源为 MIT 许可的结巴和 THUOCL，读音采用已核验整词读音、Unicode 17.0.0 单音字及 28 个新增人工核验词；未知多音字与未核验专名暂不导入。来源、原始权重与筛选哈希全部保留，安装包附版权许可声明。

关闭本地模型，“双汇火腿肠”的全拼、尾字简拼、漏一个字母、末尾相邻字母互换均为首选；康师傅方便面、充电宝也能直接输入。保留 beta.6 的纠错、候选排序和停键缓存修复。

本机冻结文章集 1,123 条与原 1,444 条组合前后对照：文章词条覆盖 30/32 → 32/32，正常首选仍为无模型 43/64、有模型 42/64；原正常首选 84/92、单处错拼首选 757/1104 保持，原成功用例无退步。新增词库能力抽测 220/220 可找到完整词条，人工核验词首选 24/28；“取件码、付款码、快递柜、抽纸”仍有同音首选问题。补入词条不等于解决整句排序，也不证明达到微软拼音准确率。Windows CI 实际结果见附件。
