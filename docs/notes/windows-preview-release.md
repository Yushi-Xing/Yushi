Windows 10 / 11 基础修复测试版，版本 **0.1.6-beta.13**。

下载 `qingjian-0.1.6-beta.13-windows-x86_64-setup.exe`。升级前退出使用输入法的程序，安装后注销再登录，使搜索进程也加载新版。保留用户配置、学习数据及 x64/x86 TSF。

本轮选择性引入五项上游修复：

- 自定义短语在 Windows 启动与配置热加载时生效，非法规则保留旧值。
- 全拼支持 `jv/qv/xv/yv`，与 `ju/qu/xu/yu` 等价，保留原按键显示与全部双拼。
- 候选含模型字表外字符时保留静态排序；同一输入条件的拒绝批次不反复重试。
- 隐藏词库文件不加载、不触发热加载。
- 拒绝预发布标识含空分段的损坏更新版本。

未更换 data-v3 和 19,662 条补充词库，未改 SearchHost 候选显示路径。本轮是基础可靠性修复，不代表“词库收纳了多少词”整句排序或 Win11 搜索遮挡已经解决；真实应用验收仍待安装确认。未签名，uiAccess 关闭。

CI 对实际发布提交执行完整可移植与 Windows 工作区回归、x86 DLL 构建、真实模型停键探针，以及期刊 306 条、拼音组合 1,444 条、文章两种模型状态各 1,123 条、词库能力 237 条评测。具体实测数值见 `build-info.json`，不要把词条覆盖当成整句准确率。本机 100 条前后探针和实施记录见仓库 `docs/notes/windows-foundation-2026-10-13.md`。
