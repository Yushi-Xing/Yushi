## 两种纠错

- **拼音无法完整切分时**（多输、少输、颠倒、输错一个字母）：`nihooma` → 你好吗，`woxiagnqu` → 我想去，`mingtain` → 明天。
  拼音行将被改动的字母以删除线标出并保留原位，候选全部按纠正后的拼音给出。
  相邻两键颠倒时不必等整个词输完：`mignt`、`migntia` 就已按 `ming't`、`ming'tia` 给出 明天，继续输入即可；
  两种纠正都说得通时优先按颠倒解释（`mignti` → 命题，而不是改一个字母的 面体）。
- **每个音节合法、整句不通顺时**：`meiganxi` 同样可出「没关系」（`gan` 视为 `guan`）。此类纠错用于候选组合中的完整音节；较长的全拼与简拼混合输入也可以纠正其中的漏键。

只有纠正后的句子明显比原样通顺时才纠正；合法的短简拼（`nhao`、`womend`）保持保守，整段为英文词的输入（`hello`）也不纠正。

## 不需要纠正时

`Enter` 仍将所敲字母原样上屏。原样上屏过一次的字母串，此后不再纠正。

## 记忆习惯性错误

被接受的纠正会被记录：习惯将 `shuo` 输成 `shou` 的用户，几次之后「我说」会自然排到前面。用 `Backspace` 删除后改选会一并撤销该记录。

双拼下不启用拼写纠错：输错一个键改变的是整个声母或韵母，单处编辑的模型不适用。五笔（形码）下同样不启用——敲的是字根编码，不是拼音。

## 混合简拼与较长输入

全拼单处拼写纠错支持最多 64 个字母；长输入也可能出现多种合理说法，不能保证首选就是你想要的句子。混合简拼中的完整音节可修复漏键，例如 `nijuedezhegdiayzenmy` 可以给出“你觉得这个电影怎么样”；音节组合的纠正未必显示单独的整串删除线标记。

“环太平洋”已补充完整词条，`huantaipingyang` 与 `huantaipingy` 都可输入。`htpy` 一类纯简拼会匹配其他同声母词，必要时补充拼音或选取候选。
