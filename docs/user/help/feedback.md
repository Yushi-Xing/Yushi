问题与建议请提到 [GitHub Issues](https://github.com/qingjian-team/qingjian/issues/new/choose)，按表单填写即可；表单会要求下面这些材料。
也可以加 QQ 群 [902314603](https://qm.qq.com/q/jBvn2gGTxm)（青简输入法用户内测体验交流群）直接交流。

先查一下 [常见问题](faq.md)，很多情况在那里有处理方法。

## 反馈时请提供

1. **日志包**：「设置 → 高级 → 日志文件 → 打包到桌面」，把日志、设置与系统信息（系统版本、架构、区域等）打包成一个文件放在桌面，反馈时附上。API 密钥会被抹去。
   也可以点同一处的「打开日志目录」自己取，位置见 [数据文件与日志](../advanced/data-files.md#运行日志)。
   Android 上是青简 App 的「数据 → 日志 → 打包日志」，选「发送给…」直接发到 QQ、微信或邮件，或选「存到手机」存成 zip；包里另有机型、系统版本、省电设置与已启用的输入法。
2. 出现问题时所在的应用、输入的内容、预期结果与实际结果。
3. 系统版本与青简的版本（「设置 → 关于」；附了日志包就不用另写）。

Windows 旧版设置程序的「关于 → 打包日志到桌面」只附常用设置摘要，不附配置原文、密钥、自定义短语、个人数据或输入日志。配置无法读取时直接省略原文件。每份运行日志最多取 8 MiB，最多 32 份、合计读取最多 32 MiB。

Windows 遇到打字不跟手时，运行日志会自动记录耗时较长的输入处理及学习数据保存时间，只含操作类别和耗时，不含具体输入内容。请同时说明卡顿发生的应用，以及是在连续打字还是选词上屏时出现。

Windows 的运行日志不再逐键记录按键、拼音与上屏文本。可复现时请说明操作步骤及预期／实际结果；必要时打开「高级 → 详细日志」收集故障线索。旧版本产生的运行日志仍可能含输入内容或未知旧密钥，分享前请检查。
macOS 与 Android 的详细日志可能含逐键内容；排查完成后请关闭。Android 的开关在「数据 → 日志」。

## 常见情况

- **安装后输入法列表中没有青简**：macOS 到「系统设置 → 键盘 → 输入法 → 编辑 → +」在简体中文下添加，仍没有则注销后重新登录；
  Windows 注销后重新登录。重启后仍然没有，请[提交 issue](https://github.com/qingjian-team/qingjian/issues/new/choose)并附系统版本与安装方式。
- **任务栏搜索框中候选被遮挡**（Windows）：新版增加搜索面板内的紧凑候选列表。升级后先注销再登录再验证，避免系统搜索进程仍加载旧版。若仍被遮挡，请反馈 Windows 版本、青简版本及是否看到候选；仅重装到默认目录不能解决未签名版本的窗口层级问题。
  开始菜单和「设置」等其他系统界面尚未统一修复。正式签名配合安全安装目录的显示方案仍需独立验收。
- **装了新版输入法后行为没变**（Windows）：输入法 DLL 会被装进每个程序的进程，**装新版之前就开着的程序要重启**才会用上新代码——在其中切走输入法再切回没有用（模块已经加载进进程了）；系统搜索建议注销再登录后验证。
  只改设置项不受此影响：保存后一秒内热加载，不用重启应用。
- **按 Ctrl + Space 切到了别的输入法**（Windows）：Ctrl + Space 是系统的「输入法/非输入法切换」，只装了青简时它切中英（与微软拼音一致），
  装了英文键盘或别的输入法时 Windows 可能改用它切换输入法，这由系统决定。青简自己的切换键在「设置 → 通用」里勾选（单击 Shift / 单击 Ctrl / Ctrl + Alt + Space）；不想要系统这条热键，到「设置 → 时间和语言 → 输入 → 高级键盘设置 → 输入语言热键」把它改成「未分配」。
- **某个应用中无法切换到青简或输入无反应**（Windows）：注销后重新登录，或重启该应用。
- **腾讯软件管理、电脑管家等安全软件中无法输入**（Windows）：这类软件带有进程自我保护（反注入），会阻止第三方输入法加载进它自己的进程；青简与其他第三方输入法（系统自带的微软拼音除外）在其搜索框内都无法输入、也无法切换中英。这是该软件的安全机制，输入法一侧无法修复。
- **打字时什么都不显示——拼音不出现、候选窗也没有**（Windows）：多半是后台服务进程 `qingjian-server` 没在跑（崩溃 / 被杀 / 装完没重启）。
  输入法连不上它时会**自己把它拉起来**，下一键即恢复；若仍无反应，从开始菜单启动「青简 Server」，或注销后重新登录。
- **候选窗口遮挡了终端 / 编辑器自身的补全**：英文模式在这些应用中缺省不给候选；被遮挡的是中文候选时，切换到英文模式即可。
- **登录后当前输入法不是青简**（macOS）：已知问题，手动切换一次即可，待签名版解决。
- **悬浮状态条不见了**（Windows）：它只在当前输入法为青简时显示；确认「设置 → 候选窗口」中的开关已打开。它每次显示时都会被移回屏幕可见范围内，不会停留在屏幕之外。
- **配置文件改错**：macOS 输入法菜单会增加一条灰色的错误说明，此时沿用上一份可用的配置；按说明改回并保存即可。
- **某个应用中表现异常**（拼音渲染异常、按键被吞、无法读取选区）：请将应用名称与现象反馈给作者；可先在「候选窗口」页更换拼音显示位置作为临时处理。
